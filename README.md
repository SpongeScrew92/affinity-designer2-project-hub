## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Project Library** | Organize all Affinity Designer 2 projects with status and client |
| **Asset Tracker** | Track shared assets and symbol libraries across projects |
| **Style Notes** | Document color and text style standards per client or brand |
| **Delivery Log** | Track exported deliverables and file versions per project |
